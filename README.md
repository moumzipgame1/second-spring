# 두 번째 봄 (SECOND SPRING)

![두 번째 봄](img/title.webp)

> 사귄 지 1년, 기념일까지 엿새. 요즘 그녀는 전보다 더 다정하다.
> "두 번째 봄은 같이 시작하고 싶어."

연애 공포 미스터리 텍스트 게임입니다. 기념일을 앞둔 일주일 동안, 다정해진 여자친구에게서 작은 어긋남을 하나씩 발견하게 됩니다.

**▶ 플레이: https://moumzipgame1.github.io/second-spring/**

## 게임 정보

| 항목 | 내용 |
|---|---|
| 장르 | 연애 공포 · 텍스트 미스터리 |
| 분량 | 8장, 약 60분 |
| 엔딩 | 6종 (숨은 엔딩 포함) |
| 플랫폼 | 웹 브라우저 (PC · 모바일) |
| 주의 | 감금, 집착, 사망 장면이 나옵니다 |

## 플레이 방법

- 장소의 **조사하기** 버튼으로 사람과 사물을 살펴봅니다.
- 얻은 물건은 **가방**에, 알아낸 사실은 **단서 노트**에 쌓입니다.
- 가방의 물건을 골라 다른 곳에 **사용**하거나, 단서를 골라 인물에게 **제시**할 수 있습니다.
- 단서가 실제로 쓰이면 화면에 **회수됨**이 떠오릅니다.
- 막히면 **힌트** 버튼을 누르세요. 방향 → 구체적인 단서 → 정답 순서로 3단계까지 알려 줍니다.
- 진행 상황은 브라우저에 자동 저장되며, 시작 화면의 **이어하기**로 돌아올 수 있습니다.
- 본 엔딩은 **엔딩 도감**에 모입니다. 마지막 분기 직전으로 돌아가 다른 선택을 해 볼 수도 있습니다.

## 시작 화면의 숫자

시작 화면에는 모든 플레이어가 그녀에게 보낸 "나도 보고 싶어" 답장의 합계가 표시됩니다. 숫자는 Firebase Firestore(`stats/replies`)에 저장되며, 보안 규칙은 [`firestore.rules`](firestore.rules)에 있습니다. 읽기는 누구나 할 수 있고, 쓰기는 숫자를 한 번에 1~3씩 늘리는 것만 허용됩니다.
